# Source (not served)
Pages are generated by `editorial/build.py`:

    python3 source/editorial/build.py     # on Windows: python source/editorial/build.py

It writes `index.html`, `prices.html`, `en/index.html`, `en/prices.html` and copies `editorial/site.css|js` to `assets/site.<hash>.css|js` (old hashes are deleted). FAQ and process wording is read from `legacy/faq.html` and `legacy/how.html`. `legacy/` holds the previous dark/gold generator (not used by the build).
