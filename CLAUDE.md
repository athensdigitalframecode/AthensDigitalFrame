# Athens DigitalFrame

Статичный сайт, Vercel деплоит из `main`. Владелец работает один. Основной язык EL, есть EN (`en/`).
Демо `/olivane/`, `/arclines/`, `/enuma/` живут отдельно (их JS не хэшируется: после правок Ctrl+Shift+R).

## Сборка
Страницы генерирует `python source/editorial/build.py` (стили `site.css`, скрипт `site.js`, тексты EL/EN в build.py через `t(el,en)`). HTML не править руками; `source/` и `docs/` не публикуются (`.vercelignore`).
Перед правками интерфейса прочитай `source/DESIGN.md` и следуй ему; если просьба противоречит, скажи и предложи вариант в стиле сайта. Скрипты без inline (CSP `script-src 'self'`), без библиотек.

## Git
- Работа в ветке `redesign`. Один коммит на изменение, чтобы откат был простым (`git revert`). Никогда force-push.
- В `main` только по команде «Push to main»: сначала `git fetch`, затем fast-forward (Claude Chat тоже пушит в main).
- Предыдущие деплои можно вернуть на Vercel через Promote.

## Цены (без ΦΠΑ)
Сайт 300€ до 3 страниц, поддержка 20€/мес, хостинг и домен 50€/год; e-shop установка 200–300€, подписка 30–50€/мес. Менять цены: здесь, в build.py и в памяти.
